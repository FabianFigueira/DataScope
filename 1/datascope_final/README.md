# DataScope — Business Data Analysis Platform

#### Video Demo: https://youtu.be/lopongoluegogogogog

#### Description:

DataScope is a web-based data analysis platform developed as my CS50x Final Project. Its main purpose is to help users analyse business datasets in CSV format through a simple, interactive and user-friendly interface.

The application allows users to create an account, log in securely and upload their own CSV files. Each user can manage their datasets and access detailed information about the data they have uploaded.

The platform uses Python and Flask for its backend, SQLite for database management, and Pandas and NumPy for data processing and analysis.

One of the main features of DataScope is its automatic data analysis system. It provides descriptive statistics, including the mean, median, minimum and maximum values. It also identifies missing values, unique values, duplicate records and potential outliers using the Interquartile Range (IQR) method.

Additionally, DataScope includes a correlation matrix that helps users identify relationships between numerical variables. The results are presented through tables and interactive visualisations using Chart.js.

The frontend was developed using HTML, CSS and JavaScript, with a dark-themed interface designed to make the platform easy to navigate.

I chose this project because I wanted to create something practical that combines several concepts learned throughout CS50x, including Python programming, databases, web development, data structures and application security. Also because i want to be a Data engineer.

Overall, DataScope demonstrates how different technologies can be integrated into a single application to make business data analysis more accessible and understandable.
